# Clipboard History Jugaad

**AutoHotkey v2** で作ったコンパクトなクリップボード履歴ポップアップ。
旧バージョンの *Clipboard History Mini* の小窓UIに着想を得ています。

[English](README.md) | **日本語**

![Screenshot](screenshot.png)

「Jugaad（जुगाड़）」はヒンディー語で「ありもので賢く作った応急の工夫」という意味。
このツールもまさにそんな感じで作りました。

## なぜ Win+V じゃダメなの？

Windows 10/11 には標準のクリップボード履歴（`Win+V`）がありますが:

| | Win+V | このツール |
|---|---|---|
| **キーボード** | Winキーが必要 — HHKB・60%キーボード・コンパクト配列だと押しにくい | デフォルト `Ctrl+Shift+H`（Winキー不要、変更も簡単） |
| **検索** | 検索ボックスなし | リアルタイム検索で数百件から一瞬で絞り込み |
| **インストール** | OS標準 | 単体 `.exe`（約1MB）、インストール不要、完全ポータブル |
| **同期** | Microsoftアカウントに同期（任意） | 100%ローカル保存 — 外部送信なし |
| **画像** | ✅ 対応 | ❌ テキスト専用（画像は Win+V を使ってね） |

Winキーのないコンパクトキーボードを使っている人、検索で素早く履歴を探したい人、
クラウド同期せずローカルだけで完結させたい人におすすめです。

## 特徴

- コンパクトな窓（デフォルト 720×420）、クラシックなWindows見た目
- リアルタイム検索（入力するだけで絞り込み）
- フィルタタブ: **All / Text / Folder / File**
  - **Text** — テキストのみ（Folder/File以外）
  - **Folder** — 実在するフォルダパス
  - **File** — 実在するファイルパス
- ListView列: **Type | Length | Content | Time**
  - `Length` = 文字数（例: `17 ch`, `1.2 Kch`）
  - `Type` = 自動判定: `Text` / `Folder` / `File` / `URL`（ピンは `*` 接頭辞）
  - Type/Length/Time は各70px固定、Content は残り幅に自動拡張
  - Content表示は種類別に絵文字付き:
    - Folder: 📁 + フォルダ名
    - File: 拡張子別絵文字（📊Excel, 📝Word, 📽️PPT, 📕PDF, 🖼️画像, 🎬動画, 🎵音声, 📦圧縮, 💻コード, ⚙️exe, 📄その他）+ ファイル名
    - URL: 🔗 + ドメイン/パス
- ピン留め / 削除 / コピー / 貼り付け、フォルダ/ファイル/URLには **Open** も
- **Open** はシェル起動: フォルダ→Explorer、ファイル→既定アプリ、URL→既定ブラウザ
- 履歴は `history.json` に永続化
- **自動パージ**: ピンなしで24時間経過した項目は起動時＋1時間ごとに自動削除（ピンは無期限保持）
- トレイメニューで **スタートアップ登録** のオン/オフ
- **Save Size** ボタンで窓サイズを保存（位置は閉じる時に自動保存）

> **画像は非対応**（テキスト専用）。画像履歴はOS標準の `Win+V` を使ってください。

## 動作環境

- Windows 10 / 11
- **AutoHotkey v2.0**（v1.1は不可）
  - ダウンロード: https://www.autohotkey.com/download/
  - またはwinget:
    ```powershell
    winget install --id AutoHotkey.AutoHotkey -e
    ```

## 起動方法

### exe版（推奨・AHKインストール不要）

[Releases](https://github.com/taroyamadax/clipboard-history-jugaad/releases) から `ClipboardHistoryJugaad.exe` をダウンロードしてダブルクリック。

> ⚠️ Windows SmartScreen が警告を出す場合があります（署名なしexeのため）。
> 「詳細情報」→「実行」で起動できます。

### スクリプト版

`ClipboardHistoryJugaad.ahk` をダブルクリック、または:

```powershell
& "C:\Program Files\AutoHotkey\v2\AutoHotkey64.exe" "ClipboardHistoryJugaad.ahk"
```

トレイに常駐し、クリップボード監視を開始します。

## トレイメニュー

トレイアイコンを右クリック:

| 項目 | 動作 |
|------|------|
| `Open` | ポップアップを開く |
| `Run at startup` | ログイン時自動起動のオン/オフ（チェック=有効） |
| `Exit` | 終了 |

`Run at startup` はユーザーのスタートアップフォルダ（`shell:startup`）にショートカットを作成/削除します。管理者権限不要、レジストリ変更なし、完全に元に戻せます。

## ショートカットキー

| キー | 動作 |
|------|------|
| `Ctrl+Shift+H` | ポップアップを開く |
| 入力 | リアルタイム検索/絞り込み |
| `↑` / `↓` | 選択移動 |
| `Enter` | 選択項目を貼り付け |
| `Ctrl+C` | 選択項目をクリップボードにコピー（貼り付けなし） |
| `Ctrl+O` | 選択のフォルダ/ファイル/URLを開く |
| `Ctrl+P` | ピン留め/解除 |
| `Del` | 削除 |
| `Esc` | 閉じる |

行を右クリックでコンテキストメニュー。フォルダ/ファイル/URLの場合は先頭に **Open** が出ます。

### 検索窓とIME（漢字変換Enter誤爆対策）

**検索窓**にフォーカスがある状態で `Enter` を押しても貼り付けは発生しません。フォーカスがリストに移動するだけです。これは意図的な設計で、日本語入力（IME）で漢字変換を確定する `Enter` が貼り付けを誤発火しないようにしています。リストにフォーカスが移った後、もう一度 `Enter` で貼り付けできます。

> `Ctrl+Shift+H`（"H" = History）はWinキーの無いキーボード（HHKBなど）を考慮し、サクラエディタの `Ctrl+Alt+H` との衝突を避けて選びました。スクリプト実行中はグローバルホットキーなので、同じキーを使うアプリと競合する可能性があります（一部ブラウザは `Ctrl+Shift+H` を履歴に使用）。競合する場合は、スクリプト先頭の `CFG` ブロックで `hotkey` を変更してください（例: `"^!v"` = Ctrl+Alt+V、`"!v"` = Alt+V）。

## 設定

`ClipboardHistoryJugaad.ahk` 先頭の `CFG` オブジェクトを編集:

| キー | 意味 | デフォルト |
|------|------|-----------|
| `hotkey` | ポップアップを開くホットキー | `^+h` |
| `maxItems` | 履歴の最大保持数 | `200` |
| `maxPreview` | Contentのプレビュー文字数 | `200` |
| `winW/winH` | デフォルト窓サイズ | 720 / 420 |
| `minW/minH` | 最小窓サイズ | 420 / 240 |
| `rememberPos` | 前回位置も復元 | `true` |
| `pinnedFirst` | ピンを上部に表示 | `true` |
| `expireHours` | ピンなし項目の寿命（時間） | `24` |
| `purgeOnStartup` | 自動パージ有効（起動時＋1時間ごと） | `true` |
| `saveFile` | 履歴JSONパス | スクリプトと同じ場所 |
| `winStateFile` | 窓状態JSONパス | スクリプトと同じ場所 |

## Type自動判定

各クリップの `Type` はその場で判定（保存しない）。`history.json` の後方互換を維持:

- `Folder` — 単一行の実在フォルダパス
- `File` — 単一行の実在ファイルパス
- `URL` — `http(s)://`、`ftp://`、`file://` で始まる
- `Text` — それ以外（複数行テキスト含む）

エクスプローラーの「パスのコピー」で付く両端のダブルクォートは除去してから判定するので、クォート付きパスも認識されます。

## 注意事項 / 制限

- **テキスト専用**。画像やファイルリストのクリップボードエントリは無視されます。
- 貼り付け時は一時的にクリップボードを書き換え、`Ctrl+V` を送信後、自己発火ガード（`g_IgnoreClip`）で自分の書き込みが再記録されるのを防いでいます。
- `history.json` はこのスクリプト専用の簡易リーダー/ライターを使用（汎用JSONパーサではありません）。
- `history.json` は **平文保存**。コピーしたパスワード・トークン・認証情報もそのままディスクに書かれます。機密情報は `Del` で削除してください。

## 自動パージ

履歴が無限に膨らむのを防ぐため、`CFG.expireHours`（デフォルト24時間）を超えたピンなし項目は自動削除:

- **タイミング**: 起動時に1回、以後1時間ごと（`SetTimer`）。長時間常駐でもPC再起動なしで整理されます。
- **残るもの**: ピン項目は年齢問わず削除されません。タイムスタンプが空の項目も残ります（年齢判定不能）。
- **基準**: 厳密に24時間経過（暦日ではない）。09:00にコピーした項目は翌日09:00に消えます。
- **無効化**: `CFG` で `purgeOnStartup: false` に設定（コード削除不要）。寿命は `expireHours` で調整。
